# xiaohey

一个用于整理、存储与分享学习资料、论文精读、课程笔记和长期思考的个人知识博客。

## 已实现

- 编辑部风格的响应式首页与暗色模式
- 论文精读、课程笔记、学习方法、读书札记、资料工具和随笔分类
- 全站关键词搜索与 `Ctrl / ⌘ + K` 快捷键
- 内容筛选、详情阅读抽屉、阅读进度
- 本机收藏、分享链接、引用格式复制、Markdown 笔记下载
- 移动端导航、键盘可访问性和减少动态效果支持
- 订阅成功反馈与基础 SEO 元数据

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 更新内容

示例文章集中保存在 `data/content.js`。新增内容时复制一条 `entries` 记录并修改标题、摘要、标签和正文分节即可，首页筛选、搜索、收藏和详情页会自动接入。

## 生产构建

```bash
npm run build
npm start
```
